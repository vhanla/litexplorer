# LiteXplorer

LiteXplorer is a lightweight and fast file explorer for Windows, built with Delphi and the VCL.

## Description

This project aims to provide a modern and efficient file explorer with a focus on performance and usability. It includes features for advanced file navigation, media viewing, and a customizable interface.

## Features

*   **High Performance:** Built for speed with a lightweight footprint.
*   **Modern UI:** Utilizes a modern, dark theme for a sleek user experience.
*   **Thumbnails View:** Browse files with thumbnail previews for images and other media.
*   **Fuzzy Search:** Quickly find files with an intelligent, fuzzy search algorithm.
*   **Media Playback:** Integrated media playback capabilities.
*   **Customizable:** Easily extend and customize the application's features.
